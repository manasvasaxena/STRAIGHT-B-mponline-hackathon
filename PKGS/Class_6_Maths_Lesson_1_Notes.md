# Class 6 Maths - Lesson 1
## Knowing Our Numbers

### 1. Numbers and Place Value

A number is made up of digits. The **place value** of a digit depends on its position.

**Example: 5,43,216**

| Digit | Place | Place Value |
|---|---|---:|
| 5 | Lakhs | 5,00,000 |
| 4 | Ten Thousands | 40,000 |
| 3 | Thousands | 3,000 |
| 2 | Hundreds | 200 |
| 1 | Tens | 10 |
| 6 | Ones | 6 |

### 2. Face Value

The **face value** of a digit is the digit itself.

**Example:**  
In **72,456**, the face value of **2** is **2**.

### 3. Indian Place Value System

The places are:

**Ones → Tens → Hundreds → Thousands → Ten Thousands → Lakhs → Ten Lakhs → Crores**

**Example: 12,34,567**

Read as:

**Twelve lakh thirty-four thousand five hundred sixty-seven.**

### 4. Comparing Numbers

To compare two numbers:

1. Count the number of digits.
2. The number with more digits is greater.
3. If both have the same number of digits, compare digits from the left.

**Example:**

**45,678 > 9,876**

**Example:**

**56,432 > 54,321**

Both have 5 digits, so compare from the left:

- 5 = 5
- 6 > 4

Therefore, **56,432 is greater**.

### 5. Ascending and Descending Order

**Ascending order:** Smallest → Greatest

Example:

**12, 25, 37, 48, 63**

**Descending order:** Greatest → Smallest

Example:

**63, 48, 37, 25, 12**

### 6. Rounding Off Numbers

Rounding makes numbers easier to use.

#### Rounding to the nearest 10

- Ones digit **0–4** → keep the tens digit.
- Ones digit **5–9** → increase the tens digit by 1.

**Examples:**

- 47 → 50
- 43 → 40

#### Rounding to the nearest 100

- 346 → 300
- 378 → 400

## Quick Practice

1. Write the place value of 7 in **5,72,416**.
2. Write the face value of 9 in **89,345**.
3. Arrange in ascending order: **45, 12, 67, 23, 8**
4. Which is greater: **56,789 or 65,789**?
5. Round **4,678** to the nearest 100.

## Answers

1. **70,000**
2. **9**
3. **8, 12, 23, 45, 67**
4. **65,789**
5. **4,700**
